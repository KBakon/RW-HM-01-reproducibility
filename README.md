# RW-HM-01 Reproducibility Code and Evidence

This repository contains the public reproducibility package associated with the manuscript:

**Critical Throughput with Reusable Skilled Workers: Parity, Temporal Slack, and Finite-Batch Feasibility Reversal**

The self-contained scientific package is located in `reproducibility/`.

For reproduction instructions, start with:

- `reproducibility/README.md`
- `reproducibility/environment/PYTHON_ENVIRONMENT.md`

The package contains the original scientific code, stored result maps, validation records, and representative witness schedules used to corroborate the analytical results.
